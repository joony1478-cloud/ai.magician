# AI가 쓴 글에서 'AI 티' 지우는 3가지 / 프롬프트 레시피형 / 글을 AI로 쓰는 직장인·블로거

## 핵심 메시지
스킬 하나 + 프롬프트 두 줄이면 AI가 쓴 한글도 사람이 쓴 것처럼 바뀐다.

## 확인된 사실
- im-not-ai: 한글 AI 글의 번역투·AI 티를 줄여주는 Claude Code 플러그인(humanize-korean). 내용(사실·인용)은 그대로 두고 문체·리듬만 바꾼다 [출처1][출처2]
- 설치: `/plugin marketplace add epoko77-ai/im-not-ai` → `/plugin install humanize-korean@im-not-ai`, 새 세션에서 `/humanize-korean` 또는 "이 글 AI 티 없애줘" [출처1][출처2]
- 예: 'AI 기술을 통해 효율을 높일 수 있다' → 'AI로 효율을 높인다' [출처2]
- 내 글 샘플을 주고 말투를 따라 하게 하는 것, 독자를 한 명으로 좁히는 것은 일반적인 프롬프트 기법 (외부 수치 주장 없음)

## 주의·한계
- im-not-ai 는 Claude Code 플러그인 → Claude Code 가 있어야 함. 없는 사람은 2·3번 프롬프트만으로도 효과
