# [카드뉴스 전체 자동화] — AI술사 운영 기획서

> 목표: **높은 조회수 + 팔로워 전환.** 한 채팅창(Claude Code 세션)이 지휘자가 되어
> 리서처 → 라이터 → 디자이너 → 캡셔너에게 일을 나눠 주고, 단계마다 검수한다.

## 1. 조직도

```
                 ┌──────────────── 지휘자 (이 채팅창 / /cardnews 스킬) ────────────────┐
                 │  주제 확정 · 단계별 검수 · 사용자 확인 · 기록 · 커밋                   │
                 └──────┬───────────────┬────────────────┬────────────────┬────────────┘
                        ▼               ▼                ▼                ▼
                ① 리서처           ② 라이터          ③ 디자이너         ④ 캡셔너
             최신 AI 소식 조사     슬라이드 문구     목업 GIF + 렌더     캡션·해시태그·DM
             research.md         script.json      PNG/MP4 + 검수      caption.md
```

| 역할 | 입력 | 산출물 | 통과 기준(지휘자 검수) |
|---|---|---|---|
| ① 리서처 | 오늘 날짜, 다룬 주제 기록 | `_candidates-날짜.md`, `research.md` | 18점 이상, 1차 출처 3개+, 날짜 확인 |
| ② 라이터 | research.md | `script.json` (표지 3안 + 표지 원형 추천) | 글자수 규칙, 2장 이탈방지, 출처 없는 사실 0 |
| ③ 디자이너 | script.json | `assets/*.gif`, `out/*.mp4·png`, `contact.png` | 미리보기에서 가독성·넘침·가림 OK |
| ④ 캡셔너 | script.json, research.md | `caption.md` | 첫 줄 125자, 해시태그 5~8, 키워드 일치 |

## 2. 사용법

| 이 채팅창에 입력 | 하는 일 |
|---|---|
| `/cardnews` | 오늘 주제 후보 TOP 3 제안 → 고르면 끝까지 제작 |
| `/cardnews 클로드로 엑셀 자동화` | 주제 지정, 바로 심층 리서치부터 |
| `/cardnews 알아서` | 묻지 않고 1순위로 끝까지 |
| `/cardnews 회고` | metrics.csv 성과 보고 다음 주 전략 조정 |

사용자가 직접 할 일: ① `out/` 의 01→NN 순서대로 인스타 캐러셀 업로드 + `caption.md` 복붙 ② 게시 2~3일 뒤 인사이트 숫자를 `metrics.csv` 에 적기(또는 불러주기) ③ (선택) 실제 화면이 필요한 주제면 화면녹화를 `assets/` 에

## 3. 폴더 구조

```
cardnews/
├─ README.md            ← 이 기획서
├─ brand/guide.md       ← 톤·주제기준·글쓰기·디자인·캡션 규칙 (모든 에이전트 공통 규칙서)
├─ brand/brand.json     ← 계정명, 인스타 아이디, 시리즈명, 프로필 링크, 색
├─ brand/reference/     ← 레퍼런스 캡처 넣는 곳
├─ template/slide.html  ← 슬라이드 템플릿 (1080×1350)
├─ mockup/kit.css, kit.js ← 목업 컴포넌트·타임라인
├─ mock.mjs             ← 목업 장면(HTML) → GIF 녹화
├─ render.mjs           ← script.json → PNG/MP4 렌더러
├─ capture.mjs          ← 실제 웹페이지 시연 녹화
├─ topics-log.md / metrics.csv
└─ posts/<날짜-주제>/  research.md  script.json  caption.md  assets/(scenes/, *.gif)  out/
```

## 4. 디자인 방식 (레퍼런스: ai.yeongseon × ai.ainow)

- **모든 장에 GIF.** 본문은 `검정 제목띠 / 흰 GIF 띠 / 검정 설명 3줄`, 표지는 GIF 전체 + 초대형 제목
- GIF 는 **목업 애니메이션**으로 자동 제작 (창·채팅·입력창·커서 클릭·타이핑·형광펜·도장)
- **별·반짝이 같은 배경 장식은 쓰지 않는다** — 움직임은 내용으로
- 표지 원형 3가지: **A 변신 / B 노란 도장 / C 주문 입력** (`guide.md` 5장, 예시 `posts/2026-10-09-ai-tone/cover-options.png`)
- 인스타 캐러셀은 GIF 를 직접 못 올리므로 렌더러가 MP4(5~15초 반복)로 변환. CTA 장만 PNG

## 5. 조회수·팔로우 전환 전략

**퍼널**: 비팔로워 도달 → 저장·공유 → 프로필 방문 → 팔로우 → 댓글 키워드 DM → 주문서 사이트 리드

| 단계 | 레버 | 담당 |
|---|---|---|
| 첫 1초 멈춤 | 표지 움직임 + 숫자 훅, 피드에서 튀는 노랑(B안) | 디자이너·라이터 |
| 끝까지 넘김 | 2장에 결과 미리보기, 장당 1메시지 | 라이터 |
| 저장 | 프롬프트·단계·목록 "나중에 볼" 정보 | 리서처 '저장욕구' 점수 |
| 공유 | "동료한테 보내줘야 할" 업무 꿀팁 | 주제 선정 |
| 팔로우 | CTA "매일 AI 꿀팁" 약속 + 시리즈화 | CTA 장, 캡션 |
| 리드 | 댓글 키워드 → 자동 DM → 주문서 사이트 | 캡셔너 + `index.html` |

운영 리듬: **주 4~5회**, 요일별 포맷 로테이션(툴발견 / 프롬프트레시피 / 튜토리얼 / 뉴스해설 / 비교·랭킹).
게시 직후 30분 고정 댓글 + 스토리 공유 + 빠른 답글. 매주 `/cardnews 회고` 로 표지 원형·훅별 저장률 비교.
