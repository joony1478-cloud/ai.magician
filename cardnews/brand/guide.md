# AI술사 카드뉴스 가이드 (모든 에이전트 공통)

## 1. 계정이 하는 일 (한 줄)
**"AI를 마법처럼 쓰는 법을, 오늘 바로 따라 할 수 있게."**
목표 지표는 **도달(조회수) → 저장/공유 → 프로필 방문 → 팔로우 → 주문서(리드) 신청** 순서.

## 2. 누구를 위해 쓰나
- 1순위: AI 써보고는 싶은데 뭘 어떻게 해야 할지 모르는 20~40대 직장인·1인 사업자·마케터·디자이너
- 2순위: 이미 챗GPT는 쓰는데 "더 잘 쓰는 법"을 찾는 사람
- 말투 기준: **똑똑한 회사 선배가 메신저로 꿀팁 알려주는 톤.** 반말 X, 딱딱한 존댓말 X → "~해요", "~하세요", "~예요"

## 3. 주제 고르는 기준 (리서처가 점수 매김, 각 1~5점)
| 기준 | 질문 |
|---|---|
| 화제성 | 지난 7~14일 안에 나왔거나 다시 뜨는 이야기인가? |
| 실용성 | 읽고 나서 **오늘 바로** 따라 할 수 있나? (업무·디자인·마케팅·일상) |
| 재미/놀라움 | "헐 이게 돼?" 반응이 나오나? |
| 시각화 | 목업 GIF로 **보여줄 장면**이 있나? (없으면 감점) |
| 저장 욕구 | 프롬프트·순서·목록처럼 "나중에 다시 볼" 정보가 있나? |

합계 18점 이상만 후보. 동률이면 **실용성 > 시각화 > 화제성** 순.
`cardnews/topics-log.md` 에 최근 30일 안에 다룬 주제와 겹치면 제외.

### 포맷 5종 (주간 로테이션)
1. **툴 발견형** — "이거 아직도 모르면 손해" 새 AI 툴/기능 1개 + 사용법
2. **프롬프트 레시피형** — 복붙 가능한 프롬프트 3~5개 (저장률 최고)
3. **따라하기 튜토리얼형** — STEP 1·2·3 화면 중심
4. **뉴스 해설형** — 큰 발표를 "그래서 나한테 뭐가 좋은데?"로 번역
5. **비교/랭킹형** — "OO 할 때 AI 툴 TOP 5", "챗GPT vs 클로드 vs 제미나이"

## 4. 글쓰기 규칙 (라이터)
- 장수: **표지 1 + 본문 3~6 + CTA 1 = 5~8장**
- 표지 제목: 2줄, 줄당 **최대 11자**(공백 포함), 숫자/구체적 결과 넣기. 핵심 단어 1~2개만 `<mark>`
- 표지 칩(알약): 6자 이내 — 계정명·툴 이름·"신기능" 등
- 본문 제목: `1. 핵심` 형태 한 줄, **12자 이내**
- 본문 설명: **3줄, 줄당 22자 이내** (문제 → 해결 → 효과). `<b>` 1개 + `<mark>` 1개까지
- 2장째에 반드시 "왜 지금 이걸 봐야 하는지" 혹은 결과물 미리보기 (이탈 방지)
- 금지: 과장된 낚시("인생이 바뀝니다"), 확인 안 된 수치, "~입니다/~합니다" 딱딱한 문체, 영어 남발, 이모지 도배
- 모든 사실·수치·기능은 리서치 노트의 **출처 URL**과 연결되어 있어야 함

### 훅 공식 (표지)
- 손해회피: "아직도 OO 직접 하세요?"
- 시간절약 숫자: "2시간 → 3분"
- 비밀/내부자: "개발자들만 몰래 쓰던 OO"
- 결과 먼저: "이 이미지, 프롬프트 한 줄이에요"
- 리스트: "퇴근 앞당기는 AI 기능 5개"

## 5. 디자인 시스템 (디자이너)
레퍼런스: ai.yeongseon × ai.ainow 캐러셀 스타일. **모든 장에 GIF**, 장마다 메시지 하나.
- 캔버스 **1080×1350 (4:5)**. 인스타가 우상단에 `1/5` 번호, 하단 110px 에 아이콘을 덮으므로 거기엔 글자 두지 않기
- 상단 중앙 작은 시리즈명: `brand.json` 의 `series` ("오늘 바로 써먹는 AI, AI술사")
- 폰트: Paperlogy(있으면) → Pretendard Black/ExtraBold. 제목은 아주 굵게, 자간 좁게
- 색: 검정 `#0b0b0b` + 브랜드 노랑 `#f2e15b` (+ 흰색). 빨강 `#d2382b` 은 "틀린 것/AI 티" 표시에만
- 강조: `<b>` 흰색 굵게, `<mark>` 노랑 반전 박스, `<mark class="w">` 흰/검 반전 박스
- **배경 장식 금지: 별·반짝이·파티클·우주 배경 쓰지 않는다.** 배경은 단색 또는 옅은 격자까지만. 움직임은 내용(타이핑·클릭·표시·도장)으로 만든다

### 레이아웃
| type | 구조 | GIF 크기 |
|---|---|---|
| `cover` | GIF 화면 전체 → 아래 어둡게 → 알약 칩(`chip`) + 초대형 제목 2줄 | **1080×1350** |
| `cover` + `"textless":true` | 제목까지 GIF 안에 직접 그림 (노랑 배경 표지 등) | 1080×1350 |
| `body` (기본) | 검정 상단띠(시리즈명 + `1. 제목`) / **흰 GIF 띠** / 검정 하단띠 설명 3줄 | **1080×660** |
| `body` + `"theme":"light"` | 전부 흰 배경, 설명은 검은 테두리 박스 | 1080×660 |
| `cta` | 저장·댓글 키워드·팔로우 3단 (GIF 없음) | – |
- 표지 GIF 는 하단 45%(y 820 아래)를 제목 자리로 비워둔다. 배경이 원래 검정이면 `"shade": false` 로 그라데이션을 끈다
- 다크/라이트 장을 섞으면(예: 2장 다크, 3장 라이트) 넘길 때 리듬이 생긴다

### 표지 3가지 원형 (AI술사용) — 예시 `posts/2026-10-09-ai-tone/assets/scenes/cover-*.html`
| 안 | 이름 | 화면 | 어울리는 주제 |
|---|---|---|---|
| A | **변신** | 검정 격자, BEFORE 창의 문제 표시→취소선→AFTER 로 교체 + 수치 미터 | 전/후 차이가 분명한 팁 |
| B | **노란 도장** | 브랜드 노랑 전체 + 종이 카드 + "인증" 도장 쾅 (제목 GIF 안) | 피드에서 튀어야 할 때, 시리즈 대표작 |
| C | **주문 입력** | 검정, 큰 입력창에 프롬프트 타이핑→전송→팁 목록 등장 | 프롬프트 레시피·목록형 |
| D | 일러스트 뉴스형 (SVG 직접 그림) | 레트로 인쇄풍 SVG + 요소별 움직임 | Figma 이미지 생성을 못 쓸 때 대체용 |
| **E (기본)** | **GPT 일러스트 뉴스형** | Figma `generate_image`(gpt-image)로 만든 레트로 인쇄 일러스트 + 사이렌·빛줄기·빛 번짐·줌 움직임 → 하단 검정 페이드 + 외곽선 칩 + 흰 제목 2줄 | **기본 표지.** 뉴스·툴 소개·꿀팁 전부 |

**E/D 표지 규칙** (E: `cover-e.html` + `cover-e.png` 가 원본)
- script: `"coverStyle":"news", "series":false, "chipStyle":"outline"`, 칩은 `AI 뉴스`/`AI 꿀팁`/`AI 툴` 같은 분류, 제목은 흰색 2줄(줄당 13자 이내, `<mark>` 안 씀)
- 일러스트 생성 (E): Figma MCP `generate_image`, model `gpt-image-2.5-flare`, 1024×1280. 파일은 Figma 'AI술사 카드뉴스 일러스트'(8eK6e9z4JP3jOzVhWvy1eD)에 쌓는다. **Figma AI 크레딧이 드는 유료 기능** — 한 편에 1~2장까지
  - 프롬프트 뼈대: "Sophisticated editorial illustration for an Instagram cover, retro risograph screen-print style with fine paper grain, halftone texture and slightly misregistered ink. Limited palette: warm vermilion red-orange, deep navy blue, soft cream paper, tiny accents of mustard yellow. Scene: <주제 장면>.   - 받은 PNG 는 `assets/cover.png` 로 저장(이미지 URL 은 7일 뒤 만료) → `cover-e.html` 을 복사해 빛·깜빡임 위치를 그림에 맞게 옮기고 `mock.mjs` 로 4초 GIF
- 상단 60%에만 그림, 하단은 어두운 땅/여백(검정 페이드 자리)
- 캐릭터: 주제의 주인공(AI 툴·회사)을 네모 몸통 캐릭터로 + **AI술사 마법사(주홍 몸통·남색 고깔모자·노란 별)** 가 매번 등장 = 계정 마스코트
- 움직임은 4초 끊김 없는 반복: 빛줄기 회전, 사이렌 깜빡임, 캐릭터 떨림/소품 흔들림, 종이 날림
- 실존 회사 로고는 그리지 않는다 (국기·건물 같은 상징이나 이름 글자로 표현)

### GIF 만드는 법 — 목업 애니메이션이 기본
레퍼런스의 GIF 는 실제 녹화가 아니라 **디자인된 UI 목업**(창 + 번호 배지 + 커서 클릭 + 타이핑)이다.
1. `assets/scenes/NN-이름.html` 에 장면을 쓴다 (`cardnews/mockup/kit.css` 컴포넌트 + `K.*` 타임라인)
   - 컴포넌트: `.k-win`(창) `.k-bar`(제목줄) `.k-term`(터미널) `.k-badge`(①) `.k-chat/.k-me/.k-ai`(채팅) `.k-input`(입력창)
     `.k-menu` `.k-card` `.k-file` `.k-hl`(형광펜) `.k-bad`(빨간 표시) `.k-strike`
   - 동작: `K.dur(초)` `K.type(sel,글,시작,속도)` `K.show(sel,시작,"up|drop|pop|left|right|fade")` `K.hide` `K.cursor([[t,x,y]..],[클릭t..])`
     `K.move` `K.sweep`(형광펜 쓸기) `K.count`(숫자) `K.cls` `K.at(t=>...)`
2. 녹화: `node cardnews/mock.mjs <장면.html> <assets/NN.gif> [1080x660|1080x1350]`
3. 실제 화면이 꼭 필요하면: 사용자 화면녹화(최우선) 또는 `capture.mjs` 로 공개 웹페이지 녹화
- 렌더러가 GIF 장을 **MP4(5~15초 반복)** 로 바꾼다 (인스타 캐러셀은 GIF 업로드 불가)
- 목업 속 UI 는 특정 회사 화면을 그대로 베끼지 말고 단순화한 일반 UI 로 (로고 사용 X)

## 6. 캡션 규칙 (캡셔너)
- 첫 줄(더보기 전 125자 안에 노출): 표지 훅을 **다른 말로** 한 번 더 + 궁금증
- 본문: 카드 내용 3~5줄 요약 (불릿 `✔︎` 또는 숫자)
- 저장 유도 1줄 + 댓글 키워드 CTA 1줄 + 팔로우 이유 1줄
- 해시태그: **5~8개**, 대형 2 / 중형 3 / 니치 2~3 (예: #AI #챗GPT #클로드 #업무자동화 #AI툴추천 #생산성 #AI꿀팁 #AI술사)
- 댓글 키워드 → DM으로 주는 자료는 프로필 링크 사이트(주문서)로 연결해 **리드 확보**
- 주문서 사이트 링크는 `brand.json` 의 `profileLink`
