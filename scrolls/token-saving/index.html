이 스킬 세 개면 해결

작업 몇 번 하고 나면 '사용 한도에 도달했습니다'… 익숙하시죠?
원인은 클로드의 '전부 다 읽고, 길게 쓰는' 방식이에요.
이 세 가지가 그걸 줄여줘요. 순서대로 해보세요!

준비물

  1. 1Claude Code데스크톱 앱 Code 탭이나 터미널, 편한 곳에서요.
  2. 2Node.js · nodejs.org LTSponytail이 쓰는 작은 훅이 node를 필요로 해요.
STEP 1

headroom · graphify 설치

터미널에서 한 줄씩 붙여넣어요.

uv가 없다면 먼저 → 맥: brew install uv · 윈도우: winget install astral-sh.uv

uv tool install --python 3.13 "headroom-ai[all]"
uv tool install graphifyy
graphify install

graphify는 패키지 이름에 y가 두 개(graphifyy)예요. 비슷한 이름은 다른 프로젝트일 수 있어요.

STEP 2

headroom으로 클로드 코드 켜기

앞으로 claude 대신 이렇게 켜주세요.

headroom wrap claude
STEP 3

ponytail 설치

켜진 Claude Code 입력창에 두 줄을 따로 입력해요.

  1. 1첫 번째 줄
/plugin marketplace add DietrichGebert/ponytail
  1. 2두 번째 줄
/plugin install ponytail@ponytail

설치만 해두면 매 세션 자동으로 켜져요.

STEP 4

graphify 실행

내 프로젝트 폴더에서 한 번요.

/graphify .

이제 셋 다 세팅 끝!

도구별로 뭐가 줄어요?

ponytail

포니테일쓰는 코드 줄이기

코드를 쓰기 전에 "이미 있는 걸 재사용할 수 없나?"부터 따지게 해서 코드를 짧게 만들어요.

작성한 코드 줄 수-54%
시간-27%
토큰-22%
비용-20%

제작자 측정값이에요. 실제 저장소(FastAPI+React)에서 기능 12개 수정 세션 평균, 모델 Haiku 4.5. 이미 코드가 촘촘한 프로젝트에선 거의 안 줄어요.

graphify

그래피파이찾는 길 미리 만들기

프로젝트를 지식 그래프(개념과 연결 지도)로 한 번 만들어 두고, 파일을 매번 다시 뒤지는 대신 지도로 바로 찾아가게 해요.

headroom 수치는 제작자 공개 예시 기준이에요.
