세 스킬이 팀원 한 명씩 역할을 맡아요.
기획자가 내 제품을 정리해 두면, 카피라이터와 광고 기획자가 그 문서부터 읽고 일해요.
순서대로 하면 10분이면 세팅 끝!

  1. 1기획자 · product-marketing내 제품·고객·경쟁사를 문서 하나로 정리
  2. 2카피라이터 · copywriting상세페이지·랜딩 카피 작성
  3. 3광고 기획자 · ad-creative메타 광고 문구·소재 기획

준비물

  1. 1Claude 유료 플랜 + Claude Code
  2. 2Node.js · nodejs.org LTS설치 명령어(npx)에 꼭 필요해요.
STEP 1

한 번에 설치

터미널에 한 줄만 붙여넣어요.

npx skills add coreyhaines31/marketingskills --skill product-marketing copywriting ad-creative -a claude-code

끝의 -a claude-code는 빼지 마세요. 없으면 Claude Code가 못 찾는 폴더에 깔려요.

다른 방법: 마케팅 스킬 50개 전부 (Claude Code 입력창)

/plugin marketplace add coreyhaines31/marketingskills
/plugin install marketing-skills

설치 후 Claude Code를 한 번 껐다 켜면 인식돼요.

STEP 2

product-marketing기획자: 마케팅 기초 문서

제일 먼저 실행해요. 한 번 만들면 매번 제품 설명할 필요가 없어요.

  1. 1상세페이지·소개글·홈페이지 링크를 주면 초안을 알아서 써요.
  2. 2자료가 없으면 하나씩 질문해요. 대답만 하면 돼요.
  3. 3결과는 .agents/product-marketing.md에 저장돼요.
/product-marketing

자료로 초안 만들기

/product-marketing 기존 상세페이지 첨부할게. 이걸로 마케팅 기초 문서 초안 만들어줘. 한국어로, 한국 20~30대 고객 기준으로 써줘.

기본 출력이 영어일 수 있어요. 처음에 "한국어로, 한국 고객 기준으로"라고 적어 두면 이후 결과물도 한국어로 맞춰져요.

STEP 3

copywriting카피라이터: 상세페이지 카피

페이지 순서대로 쓰고, 문장마다 이유와 대안을 달아줘요.

  1. 1헤드라인·서브카피·버튼 → 후기 → 문제 공감 → 얻는 것 → 이용 방법 → 망설임 해소 → 행동 유도 순서로 써요.
  2. 2버튼 문구는 '행동 + 얻는 것'으로. (신청하기 ✗ → 내 피부 타입 확인하기 ✓)
인스타 광고 보고 넘어오는 사람용 상세페이지 첫 화면 카피 써줘. 광고 문구는 '○○○'야.
신제품 랜딩페이지 카피 처음부터 끝까지 써줘. 헤드라인이랑 버튼 문구는 대안 3개씩.

없는 통계·가짜 후기는 안 지어내요. 실제 수치와 후기를 같이 주면 훨씬 좋아요.

STEP 4

ad-creative광고 기획자: 메타 광고 문구

같은 제품을 여러 각도로 뽑고, 글자 수 규격까지 검사해줘요.

  1. 1각도 3~5개 잡기 (고통·결과·사회적 증거·호기심·비교·긴급성·정체성·역발상)
  2. 2각도별 헤드라인·본문 여러 개
  3. 3규격 검사: 본문 125자 · 헤드라인 40자 · 설명 30자
메타 광고 문구 만들어줘. 각도 5개로 나누고, 각도별로 헤드라인 3개씩. 규격 넘는 건 줄인 버전도.

광고 돌린 뒤에는

  • "지난주 광고별 CTR이야. 잘된 패턴 찾아서 새 변형 만들어줘"
  • "다음에 만들 광고 형식 추천해줘"
  • "광고 댓글 모아왔어. 고객 말투로 문구 다시 써줘"

판단은 노출 1,000회는 넘긴 뒤에, 한 번에 하나씩만 바꿔서 테스트하세요.

이 순서로 쓰세요

  • product-marketing으로 기초 문서 (처음 한 번)
  • copywriting으로 상세페이지·랜딩 카피
  • ad-creative로 각도별 광고 문구
  • 매주 광고 성과를 넣고 새 변형 만들기

자주 막히는 곳

  • npx: command not found → Node.js를 설치하고 터미널을 새로 열어요.
  • 스킬이 안 보여요 → Claude Code를 완전히 껐다 켜고, -a claude-code를 붙였는지 확인해요.
  • 결과가 영어예요 → 요청에 "한국어로"를 붙이거나 기초 문서에 적어 두세요.
