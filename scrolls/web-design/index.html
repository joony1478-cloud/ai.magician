AI 티 안 나는 웹사이트,
스킬 3개로 딸깍

"웹사이트 만들어줘" 하면 늘 비슷하죠?
보라색 그라데이션, 가운데 제목, 똑같은 카드 3개.
성능 문제가 아니라 디자인 기준을 안 줘서 그래요.

준비물

  1. 1Claude 유료 요금제 + Claude Code
  2. 2Node.js · nodejs.org LTS

명령어가 어렵다면 Claude Code에 아래 GitHub 링크를 주고 "이 스킬 설치해줘"라고 하세요.

STEP 1

avoid-ai-designAvoid AI Design

AI 티 진단기. 흔적을 찾아서 고쳐줘요.

  1. 1터미널에 입력하고 Claude Code를 다시 켜요.
git clone https://github.com/funboy322/avoid-ai-design.git ~/.claude/skills/avoid-ai-design

고치기

이 페이지 AI 티 안 나게 고쳐줘

진단만 하기

AI 티 나는 부분 진단만 해줘, 수정은 하지 마

문제를 심각한 순서(P0 → P2)대로 알려줘요.

STEP 2

taste-skillTaste

뻔한 레이아웃 대신 개성 있는 디자인으로.

npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"

핵심은 레퍼런스예요

taste 스킬로 첨부한 이미지 느낌을 살려서 ○○ 랜딩페이지 만들어줘.
taste 스킬로 [홈페이지 주소] 분위기를 참고해서 ○○ 랜딩페이지 만들어줘. 똑같이 베끼지 말고 내 브랜드에 맞게.

이미지는 Claude Code 입력창에 끌어다 놓으면 첨부돼요.

STEP 3

impeccableImpeccable

명령어 하나로 폰트·여백·색을 부분별로 다듬어요.

npx skills add https://github.com/pbakaus/impeccable --skill impeccable
  1. 1처음에 서비스 정보를 알려줘요.
/impeccable init

필요할 때마다

  • /impeccable critique 뭐가 별로인지 피드백
  • /impeccable typeset 폰트가 어색할 때
  • /impeccable layout 여백·배치가 답답할 때
  • /impeccable bolder · quieter 밋밋하거나 과할 때
  • /impeccable polish 배포 전 마지막 점검

3개 같이 쓰는 순서

  • Taste로 레퍼런스 넣고 첫 버전 뽑기
  • Avoid AI Design으로 AI 티 진단·제거
  • Impeccable polish로 디테일 마감
